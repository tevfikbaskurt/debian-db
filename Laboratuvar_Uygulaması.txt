master şifresi : Master_001!
Replikasyon şifresi : Replikasyon_01!

Bu parametreler ışığında 2 node postgresql nodu oluşturup Dbeaver ile bu nodlara bağlanıp veri girişi yapınız





sudo docker network create bulut-cluster-net

sudo docker run -d --name pg-master --network bulut-cluster-net -p 5433:5432 -e POSTGRES_PASSWORD=MasterSecret123! postgres:16 -c wal_level=replica -c max_wal_senders=5 -c max_replication_slots=5


sudo docker exec -i pg-master psql -U postgres -c CREATE USER replicator WITH REPLICATION ENCRYPTED PASSWORD 'ReplicaSecret123!';


sudo docker exec -it pg-master bash

psql -U postgres

CREATE USER replicator WITH REPLICATION LOGIN PASSWORD 'ReplicaSecret123!';

CREATE ROLE replicator WITH REPLICATION LOGIN PASSWORD 'ReplicaSecret123!';

\q

exit

  -U replicator \
  -W -v -P -R -X stream
